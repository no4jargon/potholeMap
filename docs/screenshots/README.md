# README screenshot provenance

Captured on 19 October 2026 from the unmodified app in this working tree, built
with Xcode for an iPhone 16 Pro simulator running iOS 18.5 in dark appearance.
The seven phone screenshots are full-resolution simulator captures, not mockups.

The dedicated `Road Memos README` simulator was populated with three fictional
schema-v2 recordings: `Waterfront · Demo`, `City loop · Demo`, and
`Smooth road · Demo`. The route coordinates, motion samples, and passenger events
were generated for documentation. They do not contain a user's driving history
or establish actual road defects at the mapped locations.

The waterfront fixture contains 215 seconds of 100 Hz samples, three synthetic
impacts, and three synthetic passenger markers. The app's own Analyze action
produced the candidate pins and summaries shown in screenshots 03 and 04.
The recording control is shown at rest; live motion collection requires a
physical iPhone.

The waveform is `demo_drive_02` from the existing demo generator (default seed 7,
eight drives, 24 seconds per drive), a separate dataset from the phone fixtures.
To regenerate it from the repository root:

```bash
cd experiments
uv run pothole-exp demo-data /tmp/pothole-readme-experiments/demo
uv run pothole-exp run /tmp/pothole-readme-experiments/demo/recordings \
  --labels /tmp/pothole-readme-experiments/demo/labels.csv \
  --out /tmp/pothole-readme-experiments/results
cp /tmp/pothole-readme-experiments/results/plots/demo_drive_02.png \
  ../docs/screenshots/08-offline-waveform.png
```
